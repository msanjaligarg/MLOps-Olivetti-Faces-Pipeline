#  MLOps-Olivetti-Faces-Pipeline

## Overview

This repo implements an end-to-end MLOps pipeline for face recognition using the Olivetti Faces dataset. It includes:

    - Machine learning model training with scikit-learn
    - Automated CI/CD pipeline using GitHub Actions
    - Containerization with Docker
    - Kubernetes orchestration with 3 replicas
    - Flask web application for predictions
